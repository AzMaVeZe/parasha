# פרשת השבוע — אריאל ז'יטניצקי

אתר סטטי חדש לארכיון דפי פרשת השבוע, המחליף את הבלוג הישן ב-Blogspot
(https://ariel-parasha.blogspot.com/). העיצוב ממומש מתוך פרויקט
"פרשת השבוע אריאל — Design System" ב-Claude Design: קלף, כחול־דיו וזהב,
טיפוגרפיה עברית (Frank Ruhl Libre / Heebo / David Libre), RTL מלא.

## מה יש באתר

- **ארכיון מלא לפי ספר** — חמשת חומשי תורה + חגים ומועדים, עם חיפוש פרשה
  (כולל נרמול גרשיים: "טו באב" ימצא את ט"ו באב).
- **פרשת השבוע** — באדג' בהירו עם הפרשה/החג הקרוב (Hebcal, לוח ישראל),
  כפתור ישיר לדף השבוע ותצוגה מקדימה חיה שלו.
- **צפייה והורדה** — לפי `js/pdf-manifest.js` (נוצר ב-`scripts/build-pdf-manifest.sh`;
  להריץ אחרי כל הוספת קובץ). במסכי מגע הדף נפתח בלשונית מלאה (מגבלת iOS).
- **חידה לשולחן שבת מתחלפת** לפי הפרשה, עם פתרון חידת שבוע שעבר (`js/riddles.js`).
- **הרשמה ותגובות בגוגל פורמס** — ראו "הפעלת טפסים" למטה.
- **תיקיית Drive מרוכזת** — כל הקבצים זמינים גם בתיקייה אחת בדרייב,
  שממנה גם ניזונה מחברת NotebookLM "פרשת השבוע - אריאל".
- **נגישות**: דלג-לתוכן, ניהול פוקוס במודאל, ניגודיות AA, `prefers-reduced-motion`,
  הודעות סטטוס לחיפוש, והצהרת נגישות ב-`accessibility.html`.

## הפעלת טפסים (חד-פעמי, ב-Google Forms)

1. **הרשמה:** צרו טופס עם שדה אימייל, העתיקו את קישור השיתוף אל
   `SUBSCRIBE_FORM_URL` ב-`js/data.js`.
2. **תגובות (לכל דף בנפרד):** צרו טופס עם שלוש שאלות בסדר הזה:
   **פרשה** (תשובה קצרה), **שם** (תשובה קצרה), **תגובה** (פסקה), ובהגדרות →
   תשובות הפעילו **איסוף כתובות אימייל → מאומתות** (זה אימות המייל).
   - את קישור הטופס שימו ב-`COMMENTS_FORM_URL`.
   - תפריט ⋮ → **קבלת קישור מולא מראש** → מלאו ערך כלשהו בשדה "פרשה" →
     העתיקו קישור, וקחו ממנו את המזהה `entry.NNNNNNN` אל `COMMENTS_ENTRY_PARASHA`
     (כך האתר ממלא את שם הפרשה אוטומטית לכל דף).
   - בגיליון התשובות: קובץ → שיתוף → **פרסום באינטרנט** → CSV, והקישור אל
     `COMMENTS_CSV_URL`.

   כל שורה באתר תקבל כפתור "תגובות" עם מונה; התגובות מוצגות לפי דף
   (שם + תאריך בלבד; האימייל לא מוצג).

## מבנה

```
index.html          העמוד הראשי
styles.css          כניסת עיצוב יחידה (מייבאת את tokens/)
tokens/             טוקנים של מערכת העיצוב: צבעים, טיפוגרפיה, ריווח, אפקטים, פונטים
assets/icons/       אייקוני SVG (Lucide, קו 2px)
assets/pdfs/        ארכיון הקבצים (ראו README בתיקייה — הוספת קובץ = כפתורים באתר)
js/data.js          נתוני הפרשות: שם, קישור Box ישן, קובץ PDF מקומי
js/site.js          רינדור האתר, חיפוש, מודאל צפייה (JS ואניל, ללא תלויות)
```

## הרצה מקומית

```bash
python3 -m http.server 8000
# ואז http://localhost:8000
```

(פתיחת `index.html` ישירות מהדיסק תעבוד חלקית — בדיקת זמינות ה-PDF דורשת שרת.)
