# הבקשה ל-NotebookLM לפרקי הפודקאסט

כך נוצרים הפרקים: במחברת **פרשת השבוע** מסמנים **רק** את הדף של הפרשה, ובוחרים
סקירה קולית (Audio Overview) בעברית, בסגנון "דיון מעמיק" (Deep dive). בשדה ההנחיה
מדביקים את הנוסח שלמטה — כל פרשה בנפרד, עם השם שלה.

הסקריפט `scripts/make-episode.py` שולח בדיוק את הנוסח הזה (`PROMPT`), ומריץ את כל ספר
שמות בפקודה אחת: `python scripts/make-episode.py --book שמות`.

## הנוסח

```
פרק פודקאסט בעברית: שני מנחים בשיחה, שמנתחים ודנים ברעיונות שמופיעים בדף של {title} — רק בדף הזה, מתוך המקור שסומן. פתחו בשאלה או בתמיהה שהדף מעלה, עקבו אחרי מהלך הטיעון של הכותב שלב אחר שלב, הביאו את הפסוקים, המדרשים והפרשנים שהוא מצטט, והגיעו למסקנה שלו. מותר לשאול ולהתווכח, אבל לא להוסיף פרשנות או עובדות שאינן בדף. הדף נכתב על ידי אריאל ז'יטניצקי, מתוך הסדרה "בין הנכתב לנגלה".
```

## אחרי שהפרק מוכן

1. להוריד את הקובץ ולשמור אותו בשם שמתחיל בשם הפרשה: `פרשת וארא - בין הנכתב לנגלה.m4a`.
   הסקריפט שומר כך מעצמו.
2. לשמוע אותו לפני ההעלאה — הוא יוצא בשם הסדרה.
3. להעלות ל-Spotify for Creators עם הכרטיס מ-`assets/covers/`, ולהוסיף בתיאור את הקישור לעמוד
   הפרשה באתר.
4. לשלוח ל-Claude את קישור הפרק, כדי שייכנס לאתר.
