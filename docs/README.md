## מה שנשאר פתוח

1. **הגדרות Cloudflare Pages** — צריך לשנות ידנית ל-`bash scripts/build-site.sh` ו-`dist`. עד שזה ייעשה, האתר מגיש גם את `worker/` ואת `scripts/`.
2. **GitHub Pages** עדיין מוגדר ומנסה לפרוס לשווא — כדאי `Settings ‹ Pages ‹ Unpublish site`.
3. **חידת תרומה תשס"ט** — בדף כתוב "את חידת השבוע צירפתי בגוף המייל". החידה לא בדף; אולי שמורה בתיבת המייל.
4. **שתי הגהות בדפים** — בפינחס מודפס "לנקודה א'" פעמיים, ובשלח לך נראה ששני הדוברים בדיאלוג התחלפו. לא תוקנו: זה טקסט של אריאל.
