# ארכיון ה-PDF של האתר

לכאן מעלים את קובצי הדפים. שורה באתר מקבלת כפתורי **צפייה** ו**הורדה** אוטומטית ברגע
שהקובץ קיים כאן בשם שמוגדר לה ב-`js/data.js` — אין צורך לגעת בקוד.

כל הקבצים נמצאים בתיקיית ה-Drive המרוכזת:
https://drive.google.com/drive/folders/1waquTTctSg9xvaC6ehHtS4pLDhNDIP9l

## שמות הקבצים שהאתר כבר מכיר

| קובץ | פרשה |
|---|---|
| `bereshit-תולדות.pdf` | תולדות |
| `devarim-דברים.pdf` | דברים |
| `devarim-ואתחנן.pdf` | ואתחנן |
| `devarim-שופטים.pdf` | שופטים |
| `devarim-ניצבים-וילך.pdf` | ניצבים / וילך |
| `sefer-בראשית.pdf` | אסופת ספר בראשית |
| `sefer-שמות.pdf` | אסופת ספר שמות |
| `sefer-ויקרא.pdf` | אסופת ספר ויקרא |

## הוספת פרשה חדשה

1. מעלים את הקובץ לכאן (למשל `bereshit-נח.pdf`).
2. ב-`js/data.js` מוסיפים לשורת הפרשה: `pdf: P('bereshit-נח.pdf')`.
