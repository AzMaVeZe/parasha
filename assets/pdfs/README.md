# ארכיון ה-PDF של האתר

כל דפי הפרשה, בשמות אחידים: `<ספר>-<פרשה>.pdf` (למשל `bereshit-נח.pdf`,
`chagim-פסח.pdf`). דפים שנכתבו לשתי פרשות מחוברות מופיעים כקובץ אחד
(למשל `vayikra-תזריע-מצורע.pdf`) ושתי השורות באתר מצביעות עליו.

שורה באתר מקבלת כפתורי **צפייה** ו**הורדה** אוטומטית ברגע שהקובץ שמוגדר לה
ב-`js/data.js` קיים כאן — אין צורך לגעת בקוד כדי להוסיף קובץ קיים.

הקבצים זמינים גם בתיקיית ה-Drive המרוכזת (המקור):
https://drive.google.com/drive/folders/1waquTTctSg9xvaC6ehHtS4pLDhNDIP9l

## מה חסר עדיין

- `chagim-יום-כיפור.pdf` — אין דף ליום כיפור בארכיון.
- אסופות הספרים `sefer-בראשית.pdf`, `sefer-שמות.pdf`, `sefer-ויקרא.pdf` —
  כפתור "האסופה המלאה" יופיע מעצמו אם יועלו.
- `shmot-תרומה-תשע.pdf` — דף תרומה שני (תש"ע) שמור כאן ואינו מקושר; השורה
  מצביעה על דף תשס"ט.

## הוספת פרשה חדשה

1. מעלים את הקובץ לכאן בשם לפי המוסכמה.
2. ב-`js/data.js` מוסיפים לשורת הפרשה: `pdf: P('<שם הקובץ>.pdf')`.
