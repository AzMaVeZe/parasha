# פודקאסטים (NotebookLM)

לכאן מעלים קובצי שמע של פודקאסט לכל דף. כפתור **האזנה** ונגן מוטמע מופיעים
באתר אוטומטית ברגע שקובץ קיים כאן, ללא נגיעה בקוד.

## כלל השמות
אותו שם בסיס כמו ה-PDF, בסיומת `.m4a` (או `.mp3` / `.wav`):

| ה-PDF | קובץ השמע |
|---|---|
| `bereshit-נח.pdf` | `bereshit-נח.m4a` |
| `devarim-שופטים.pdf` | `devarim-שופטים.m4a` |
| `chagim-פסח.pdf` | `chagim-פסח.m4a` |

## איך מייצרים פודקאסט ומעלים (5 דקות לכל דף)
1. במחברת **"פרשת השבוע - אריאל"** ב-NotebookLM, בחרו את מקור/מקורות הדף.
2. בלוח **Studio** לחצו **Audio Overview → Generate** (אפשר "Customize" כדי
   לבקש עברית / אורך / דגש). המתינו לסיום.
3. בתפריט הפודקאסט → **Download** (מתקבל קובץ שמע).
4. שנו את שם הקובץ לפי הטבלה למעלה והעלו אותו לתיקייה זו.
5. הריצו `bash scripts/build-audio-manifest.sh` ועשו commit — הכפתור יופיע.

> אין דרך אוטומטית לייצר את הפודקאסט מחוץ ל-NotebookLM; שלבים 1–3 ידניים.
> לאחסון חלופי אפשר לשים בשורת ה-data.js כתובת מלאה: `audio: 'https://…'`
> (יש להוסיף את הדומיין ל-`media-src` ב-CSP שב-index.html).
