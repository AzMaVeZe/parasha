# הספר — עימוד לבוקפוד

כל דפי "בין הנכתב לנגלה" בספר אחד, לדפוס ולדיגיטל ב[בוקפוד](https://bookpod.co.il/).
בשלב הזה: **פרק לדוגמה** (בהעלותך) בשלושה עיצובים.

**הוחלט (3.11.2026): 17×24, עיצוב ג (מודרני).** כותרות באסיסטנט, גוף בדוד, פסוקים בפרנק רוהל
עם פס בצד, מספר עמוד למעלה ליד הכותרת הרצה, בלי הזחת פסקה. עמודי הפנים בשחור בלבד.

## הדוגמאות

| `ג-מודרני-17x24.pdf` | כותרות באסיסטנט, גוף בדוד, פסוקים עם פס בצד כמו באתר, מספר עמוד למעלה |

## איך זה בנוי

```
book/
  make_sample.py      הטקסט (מ-assets/sheet-text) ← HTML לכל גודל ועיצוב
  instance_fonts.py   גופני האתר ← TTF סטטיים (ראו למטה למה)
  render.js           HTML ← PDF, דרך Chromium ו-Paged.js
  vendor/paged.polyfill.js   Paged.js 0.4.3 — מחלק לעמודים, הערות שוליים, כותרות רצות
  build/              תוצרים, מחוץ לגיט
  samples/            ה-PDF-ים שנשלחו לאריאל
```

להרצה (מתיקיית הריפו):

```
python3 -m venv /tmp/venv && /tmp/venv/bin/pip install fonttools brotli
/tmp/venv/bin/python book/instance_fonts.py
python3 book/make_sample.py
node book/render.js sample-17x24 sample-14.8x21 design-b-17x24 design-c-17x24
```

## מה למדנו בדרך

- **הטקסט בא מה-PDF, לא מה-Word.** קובצי ה-Word שבדרייב ("מסמכי word doc לא סופי") הם טיוטות
  מוקדמות: "שבת תרומה תשסט.doc" הוא בכלל תצוה, ורק 27% מהמילים שבו תואמות את הנוסח הסופי.
- **כל דף צריך עריכה לפני עימוד.** הדפים בשני טורים: בחילוץ פסקאות נשברו, הערות השוליים נכנסו
  לגוף הטקסט ומקום הסימון שלהן אבד, וכיתובי תמונה השתרבבו פנימה. בבהעלותך זה תוקן ביד
  (`make_sample.py`), ומקום ההערות הוא ניחוש שאריאל צריך לאשר.
- **Paged.js וכיוון RTL:** כשהמסמך כולו RTL, Paged.js לא מזהה גלישה לעמוד הבא, והכל נשאר בעמוד
  אחד. לכן `<html>` נשאר LTR, והתוכן, הכותרות והערות השוליים מקבלים `direction: rtl`.
- **גופנים משתנים יוצאים Type 3.** Chromium ממיר גופן משתנה (variable) ל-Type 3, ובתי דפוס לא
  אוהבים את זה. `instance_fonts.py` מייצר עותק סטטי לכל משקל, וה-PDF יוצא עם TrueType מוטמע.
- **שחור-לבן.** הדפסה צבעונית יקרה בהרבה, ולכן אין צבע בעמודי הפנים — גם לא הזהב של האתר.
- **ספר עברי נפתח מימין:** עמוד אי-זוגי הוא השמאלי בכפולה, השדרה מימינו, והשוליים הפנימיים רחבים יותר.
- **רישיונות:** הספר נמכר, ולכן אין בו נוסחים מספריא שהם CC-BY-NC. הציטוטים שבדפים עצמם הם של אריאל.

## דרישות בוקפוד (לאמת בלוח הבקרה לפני הגשה)

שני קבצי PDF — פנים הספר, וכריכה נפרדת (חזית, גב ושדרה; רוחב השדרה לפי מספר העמודים וסוג
הנייר, במחשבון שבלוח הבקרה). בלי סימני חיתוך, שטוח בלי שכבות, גופנים מוטמעים. לספר הדיגיטלי:
EPUB. מומלץ להזמין עותק בדיקה אחד לפני פרסום.
